# 既有分析复现性体检报告（Before）

> 对象：一份既有的口腔癌树突状细胞单细胞分析（作者与单位信息已隐去）
> 材料：分析文档、10 个 R 脚本、10 个样本的 rds、4 张结果图、3 个结果表
> 说明：原脚本未随本仓库发布；文中行号供作者自查，不影响结论的可读性。
> 结论先行：**原分析的核心生物学发现（DC 五分型）大体成立，但整条分析流程无法端到端复现，
> 且有 4 处会直接导致结论失效的方法学问题。** 因此不建议"修补"，建议按本仓库的方式重建。

| GSE172577 | 6 例未经治疗舌部 OSCC 原发肿瘤 | 6 例 OSCC，原文主题为 *TCF7+ T 细胞 / TLS*（[Oral Oncol 2021, PMID 34044317](https://www.omicsdi.org/dataset/geo/GSE172577)） | 样本数对，**"侧重 T 细胞"未说明对 DC 分析的影响** |
| GSE193766 | 2 例 OSCC 的肿瘤及配对癌旁（=4 样本） | 4 样本（2 癌 + 2 癌旁），原文主题为 *γδT17 / c-Maf*（[Sci Adv 2022, PMID 35613277](https://www.omicsdi.org/ws/dataset/geo/GSE193766.xml)） | 样本结构对，**数据集目的与 DC 无关** |

**这是全篇最要命的隐藏限制**：两套数据都是"为 T 细胞设计"的 10x 数据，DC 天然稀少。
按原分析自己的 DC 亚群细胞数（50–358/簇）推算，DC 总量约 **1,842 个细胞（≈1.7%）**，
且来自 8 个患者。用这个规模去论证"代谢可塑性""迁移能量供给"，统计功效不足。
重建版把这个限制写进 `docs/limitations.md`，并在方法上做样本水平的保守推断。

## 3. 代码级缺陷（按严重度）

### 3.1 致命：主流程脚本第一步就中断

`最终版本.R` 第 26、34 行：

```r
gse1_files <- list.files(gse1_dir, pattern = "GSM525838[5-9]|GSM5258390", full.names = TRUE)
```

`rds/` 目录下每个样本有 5 个文件（`_diagnostics / _mat / _metaData / _sce / _seurat`）。
**实测该正则匹配到 30 个文件而不是 6 个**（已运行验证）。紧接着 `qc_filter()` 对
`_diagnostics.rds`（一个 list）调用 `PercentageFeatureSet()`，必然报错；
即使不报错，同一批细胞也会被重复读入 5 次，整合时的"批次"就变成了"文件格式"。

### 3.2 致命：差异基因模块引用了不存在的列

`最终版本.R` 第 80–113 行：`FindMarkers(ident.1 = 1)` 只比较 **一个** cluster，
输出没有 `cluster` 列；但第 104、112 行 `group_by(cluster)`、`top_n(20)` 都依赖该列。
→ 该脚本**不可能**产出原分析中"每个 cluster 前 20 个 marker"的结果，`final_top_markers.csv`
在目录中也不存在。

### 3.3 致命：注释链条断裂

`最终版本.R` 第 76 行 `p2 <- DimPlot(seurat_data, ...)`，`seurat_data` 从未定义；
第 160 行 `DimPlot(combined, group.by = "cell_type")`，但第 156 行 `RenameIdents()`
只改 Idents，**不会生成 `cell_type` 列**；第 163–164 行又重新读入 `rds.rds` 并访问
`combined@meta.data$`cell type`` —— 三个对象名、两种列名互相打架。

### 3.4 致命：SingleR 参考集被"洗坏"

`转换标志.R` 第 104 行：

```r
rownames(ref) <- sub("-.*", "", rownames(ref))   # 想去掉 "-AS1" 之类的后缀
```

`-` 是基因名里的普通字符，这一行会把 **所有带连字符的基因名截断**：
`HLA-DRA → HLA`、`HLA-DRB1 → HLA`、`HLA-A → HLA`…… 参考集瞬间塌缩成大量重名基因，
`intersect()` 后 `ref[common_genes, ]` 只能取到第一个同名行。SingleR 的参考谱因此失真。
`可视化/注释数据集BlueprintEncodeData.png` 中**几乎所有细胞被判为 Monocytes**，
与该缺陷的表现完全一致。

同一文件第 49 行 `sub("\\\\..*", "", ...)` 想删 Ensembl 版本号，但多转义了一层，
正则实际是"反斜杠+任意字符"，对 `ENSG...` 无任何作用（无效代码）；
第 20 行 `if(!"data" %in% Layers(combined))` 在 Seurat v5 下语义不可靠，会导致重复标准化。

### 3.5 严重：DC 亚群脚本对象错位

`DC细胞亚聚类.R`：

- 第 9–11 行先 `DC = readRDS('DC注释.rds')`，下一行就用**从未定义**的 `scRNA1`
  （第 10 行 `colnames(scRNA1@meta.data)` 直接报错）；
- 第 46–48 行 `FindAllMarkers(object = DC, ...)` 用的是**重聚类之前的旧对象**，
  产出的 marker 与 11 个亚群无对应关系，却被当作亚群 marker 写进 `top10.csv`；
- 第 84、87 行同时出现 `cell_type` 与 `celltype` 两列，`cell_type` 被填成字符串 `"NA"`，
  后续 `subset(..., celltype %in% ...)` 能跑但画图用 `cell_type` 就是一片 NA；
- 亚群注释 `c(7)`, `c(10,2,6,0,3)` 等是**手工按 UMAP 位置**指定，无 marker 富集检验支撑。

### 3.6 严重：两份脚本是"别人家的"

- `参考文件处理.R` 载入 `NEU.seurat.rds` / `NEU_exprmat.rda`（1.1 GB），
  注释表却是 `Fibroblast / Alveolar cell / Colon epithelial` —— **肺/结肠**的细胞类型，
  与口腔癌无关；末尾 `saveRDS(seu, ...)` 的 `seu` 对象不存在。
- `轨迹推断分析（Monocle）.R` 混用 monocle3 与 monocle2 函数
  （`plot_cell_trajectory` 是 monocle2 的），`combined_seurat` 未定义，
  还在分析脚本里夹了 `BiocManager::install("SCENIC")`。

### 3.7 一般：语法与隐含依赖

| 文件 | 行 | 问题 |
|---|---|---|
| `富集分析.R` | 34 | 一行裸中文 `查看Ｔ细胞差异基因数据的列名` → 语法错误，整份脚本无法 `source()` |
| `富集分析.R` | 13–14 | `markers`、`significant_markers` 未定义（依赖别的脚本留下的全局变量） |
| `script.R` | 15 | 括号未闭合 |
| `script.R` | 4–5 | 路径少了 `rds/` 子目录 |
| `拟时序分析.R` | 73 | `order_cells(cds)` 交互式点选根节点，未记录、不可复现 |
| `拟时序分析.R` | 98–99 | `time[time==Inf]=0` 把"未分配伪时间"当成起点 0，污染下游 |

## 4. 方法学问题（比代码错误更影响可信度）

1. **QC 参数三处不一致，且原分析正文与代码不符。**
   原分析 2.2 写 `nFeature 200–5000 / nCount 500–30000 / mt<15%`；
   原分析 2.3.1 写 `UMI≥401 / 基因 201–6000 / mt≤25%`；
   `qc加mormal.R` 又是 `200–6000 / 500–30000 / mt<15%`。三套数字，无法判断最终用了哪套。
2. **没有去 doublet、没有 ambient RNA 校正。** 口腔黏膜组织解离极易产生双细胞，
   而"迁移型 DC 高表达 CCR7 + 上皮 marker"这类组合很容易被双细胞伪造成中间态。
3. **整合后二次 QC 静默失效。** `qc加mormal.R` 第 77 行在 `DefaultAssay = "integrated"`
   上算 `percent.mt` —— integrated assay 只有 2000 个高变基因，几乎不含 MT 基因，
   过滤条件形同虚设。
4. **在 integrated assay 上做差异分析。** `FindMarkers` 默认 assay 是 integrated；
   经过批次校正的表达值再做 Wilcoxon，p 值不可解释。应在 `RNA` assay 上做。
5. **富集分析把双向基因混在一起，却分别归因于两个亚群。**
   `富集分析.R` 第 77 行取 `abs(avg_log2FC) > 1`（上调+下调都进），
   产出**一张** KEGG 图（`C2_CLEC10A vs C3_CCR7 KEGG.png`），
   正文却写"C2 富集结核病通路、C3 富集 NF-κB 通路"。方向性结论没有对应的分析支撑。
6. **注释策略没有兑现原分析自己的承诺。** 2.3.3 明确说要"用 CNV 推断区分恶性细胞与非恶性上皮"，
   但全部脚本中没有任何 CNV 分析（inferCNV/CopyKAT 皆无）。
7. **没有样本水平统计。** 8 例患者（正常组织仅 2 例），所有结论都建立在
   "细胞数"而非"患者数"上；没有伪 bulk、没有混合模型、没有比例检验。
8. **可复现性为零。** 无 `sessionInfo()`、无随机种子、无版本锁定、无中间对象、
   脚本之间靠全局变量传递、根节点靠鼠标点。

## 7. 哪些结论站得住，哪些要降级

| 原分析结论 | 证据强度 | 处理建议 |
|---|---|---|
| DC 可分为 cDC1 / cDC2 / 迁移型 / pDC / CD207+ 五群 | **强**（marker 是教科书级） | 保留，重建版用 marker + 参考集双证据复核 |
| C2(cDC2) 占多数、C3 为 CCR7+ 迁移态 | **强**（与 HCC/泛癌 LAMP3+ DC 文献一致） | 保留，升级为"cDC2 → mregDC 成熟轴" |
| 拟时序证明 C2→C3 分化 | **弱**（无根节点记录、无速率、无独立验证） | 降级为"转录连续谱"，与速度/文献一致性并列陈述 |
| C2 通过 CLEC10A 介导脂质代谢与结核病通路 | **弱**（合并基因集，方向未拆） | 改为"差异基因在脂质/抗原加工相关条目富集"，分开做上调/下调 |
| RACK1 + ATP 合酶驱动迁移能量供给 | **很弱**（4 基因模块 + 未验证） | 降级为探索性假设，或直接删除 |
| CLEC10A→IDO1→色氨酸代谢重塑免疫抑制 | **无**（原分析中无 IDO1 表达证据） | 删除或作为"待检验假设"单列 |

## 8. 结论

原有分析的问题不是"代码写错了几个字母"，而是**分析链条上每一环都缺少可核查的中间产物**：
参数三套、marker 与亚群错位、注释参考集被洗坏、富集方向未拆、图来自别的对象。
在这样的基础上"改一改让它跑通"，得到的仍然是一个无法在面试中自证的流程。

因此本项目选择**从原始 counts 重建**（`R/01` → `R/09`），把每个数字都落成可检查的表格与图，
并在 `docs/methods.md` 里逐条写明"为什么这样设参数"。重建后的结论比原分析更保守，
但每一条都能追溯到具体的脚本行和结果文件。
